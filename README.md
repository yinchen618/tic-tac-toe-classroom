# 井字遊戲教學示範（Tic-Tac-Toe Classroom）

這是一個以純靜態 HTML、CSS 與 JavaScript 建立的井字遊戲課堂教學示範專案，內建確定性極小化極大演算法（Minimax）即時戰術分析，具備完整行動裝置響應式設計（RWD）與多國語系切換，適合直接部署於 Vercel。

## 功能特色

- **多國語系即時切換**：支援 4 種語系切換（繁體中文 `zh-Hant`、英文 `en`、日文 `ja`、印尼文 `id`），介面標題、對戰模式、回合狀態、說明頁與 Minimax 戰術解析即時連動並自動記憶偏好（`localStorage`）。
- **完善的行動裝置響應式設計（RWD）**：
  - 遵循行動優先設計，支援最小 320px 窄螢幕至桌機高解析度螢幕。
  - 包含視窗安全區域邊界（`safe-area-inset`）保護，支援瀏海螢幕。
  - 所有按鈕、選單與棋盤觸控目標皆符合 WCAG 標準（觸控目標高度 ≥ 44px）。
  - 排版採用 `text-wrap: balance` 與 `overflow-wrap: break-word`，多語系長字串無破版與截字問題。
- **雙模式支援**：支援「單人對抗電腦」（玩家執 `X`、電腦執 `O`）與「雙人同機對戰」。
- **1 至 9 格編號**：棋盤每一格皆標示 `1`–`9` 號，方便課堂討論與對應戰術說明。
- **確定性 Minimax 戰術解析**：每一步棋後即時提供最佳合法落子建議與多語系真實原因說明：
  1. **立即獲勝（Win）**：直接連成三子獲勝。
  2. **阻擋對手（Block）**：阻止對手下一手直接連線。
  3. **創造／破解岔路（Fork / Block Fork）**：同時形成兩條聽牌路線，或防止對手形成雙活。
  4. **佔領中心（Center）**：控制涵蓋 4 條連線方向的第 5 格。
  5. **佔領角落（Corner）**：建立穩固的角落攻防據點（第 1、3、7、9 格）。
- **防呆與計時器安全控制**：遊戲結束與電腦思考期間鎖定棋盤；重新開始或切換模式時自動取消待執行的電腦步數。

## 本機執行與自動化測試

### 啟動本機預覽伺服器
```bash
python3 -m http.server 8080 --bind 127.0.0.1
```
接著於瀏覽器開啟 `http://127.0.0.1:8080`。

### 執行自動化測試
學生可隨時使用 Node.js 執行內建測試腳本，驗證 8 條獲勝連線、平手、阻擋、五大戰術解析、電腦 AI 窮舉不敗、UI 重開行為與 4 國語系切換：
```bash
node test_game.js
```
